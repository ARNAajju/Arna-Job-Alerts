# Arna Job Alerts

Government jobs, results, hall tickets and schemes portal with Firebase Admin panel.

## Public site
- `index.html` — homepage
- `job.html`, `results.html`, `halltickets.html`, `schemes.html` — modules
- PWA: `manifest.json`, `sw.js`, `offline.html`

## Admin
- Login: `/admin/login.html`
- Dashboard, Manage Jobs, Results, Hall Tickets, Schemes
- Analytics, Notifications, Users, Login History, Settings

## Stack
Static HTML/CSS/JS + Firebase Auth/Firestore + Cloudinary
